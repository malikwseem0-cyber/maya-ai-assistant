# Maya Assistant

Maya Assistant is an advanced personal AI assistant designed for Android and Windows.

## Features

- 🤖 AI chat and conversation
- 🎙️ Voice interaction
- 🧠 Long-term memory
- 🧩 Multi-agent system
- 💻 Windows PC remote control
- 📱 Android app builder
- 👨‍💻 Programming assistant
- 📷 Camera and vision features
- 📅 Calendar and reminders
- 🌤️ Weather dashboard
- 🎭 Custom AI personas
- ⚡ Fast streaming responses
- 🌙 Futuristic dark AI dashboard
- 🔐 Secure API key and device pairing

## AI Providers

Maya is designed to support multiple AI providers, including:

- Google Gemini
- OpenAI

API keys are configured by the user and are not hard-coded into the application.
